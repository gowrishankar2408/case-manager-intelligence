# Use Cases

## Case Context Review

An authorized case manager requests a case summary and reviews its details, notes, activities, history, and attachments with source references.

## Similar Case Discovery

A case manager searches for comparable resolved cases and compares the retrieved evidence, outcomes, and applicability to the current case.

## Closure Explanation

A case manager asks why a case was closed. CMI assembles a timeline, ranks evidence, identifies gaps or conflicting signals, and returns a traceable explanation with calibrated confidence. The explanation supports human review; it does not replace the case manager's judgment.

## Access and Audit

Every use case must enforce the caller's case-level permissions and record a privacy-conscious audit event without copying unnecessary sensitive content into logs.
