# Roadmap

## Foundation

- Confirm system-of-record APIs, identity, access, and data classification.
- Define shared case, activity, attachment, evidence, and response schemas.
- Add synthetic fixtures and unit tests for tool contracts.

## Retrieval and Reasoning

- Implement extraction, normalization, redaction, chunking, embeddings, and indexing.
- Build retrieval evaluation and source-attribution checks.
- Implement timeline, evidence ranking, confidence, and closure analysis with human-review safeguards.

## Pilot

- Integrate the MCP server with an approved agent and authenticated services.
- Run a limited pilot with monitoring, audit review, user feedback, and rollback criteria.

## Production Readiness

- Complete security, privacy, governance, operational, accessibility, and model risk reviews.
- Establish release, incident, retention, and quality regression processes.
