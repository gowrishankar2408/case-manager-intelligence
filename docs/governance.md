# Governance

## Human Oversight

Generated summaries and closure explanations are decision support. A qualified case manager remains responsible for interpretation and action. The system must communicate uncertainty and preserve links or identifiers to supporting evidence.

## Data and Model Controls

- Assign owners for source data, schemas, prompts, models, indexes, and evaluation datasets.
- Track data provenance, permitted use, retention, and deletion across derived artifacts.
- Version prompts, retrieval configuration, models, and tool schemas; review changes before release.
- Evaluate factual grounding, retrieval coverage, confidence calibration, subgroup effects, and failure modes.
- Record limitations and route low-confidence or conflicting evidence to human review.

## Change and Incident Management

Use documented approvals for production changes. Provide an incident path for privacy, security, data quality, and harmful or misleading outputs. Reassess controls whenever data sources, models, or use cases change.
